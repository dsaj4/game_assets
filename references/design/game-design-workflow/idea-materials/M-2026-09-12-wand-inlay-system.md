## 规范化表述

### IN-A：用户已明确的模型

镶嵌作用于法杖，用于强化完整法术，效果可与法术类型或明确法术特征相关，是流派组件。每根法杖自带一个初始固定镶嵌，代表法杖身份，规定基础施法范围及可选特殊效果；特殊效果多数与法术类型有关，但不要求每根法杖都有特殊效果或只能强化一种类型。

固定镶嵌与法杖身份绑定；初始固定镶嵌必定存在，不能再写作“是否预配Unknown”。具体是哪款法杖、范围形状／尺度及其特殊效果仍须逐件设计。修饰词改变句内原词，镶嵌作用于法杖上的完整法术或明示范围事件，不能自动让不合法句子变合法。

用户已确认“简易法术加速”的隔周期含义及“燃烧效果强化”的范围被动含义，见IN-X01／IN-X02。其他获取、装配与运行细则按下方Candidate呈现，未全部写成核心默认。

### 补充候选总表

以下是按用户“剩下的获取、装配等规则你先补充”形成的一套推荐方案。2个活动槽、每店各1个专属商品位等均为首轮候选规模，需与经济和成长一起验证。

| 编号 | 推荐规则 | 设计目的 |
| --- | --- | --- |
| IN-C01 结构 | 每杖1个固定镶嵌＋2个可换镶嵌槽；固定不占活动槽，活动槽可空 | 身份稳定，同时允许组合 |
| IN-C02 装配 | 可换镶嵌在战前免费拆装，不损坏；一件实体只装一根法杖；固定镶嵌不可拆卸、转移或单独出售 | 允许试配，以占槽而非拆装费限制组合 |
| IN-C03 持有 | 可换镶嵌每个ID每局最多1件，已装与未装合计；库存不设额外总容量；同款法杖可有多根实体 | 避免重复购物成为默认成长，保留跨杖调配 |
| IN-C04 获取 | 可换镶嵌和新法杖先只通过商店金币购买；每店分别1个专属位，不占普通词卡名额 | 复用已存在的决策渠道并比较花钱方向 |
| IN-C05 货架 | 从各自合格池按名称等概率抽取，公开且本次固定，一条目1份、售出不补货；不足按实际提供，空池无补偿 | 继承现有商店行为，不暗调适配或余额 |
| IN-C06 交易与法杖替换 | 成交复查资格／足额金币，购买进入库存；替换出战法杖不增加出战上限，先卸回活动镶嵌再重新配置 | 得到新法杖不等于免费新增并行法术 |
| IN-C07 初始与跨战 | 起始法杖均带自己的固定镶嵌，活动槽初始为空；镶嵌及法杖在本局跨战保留，计数每战重置；新局重置 | 获得组件形成局内成长，避免跨战攒触发 |
| IN-C08 激活 | 仅已出战且绑定完整合法法术的法杖激活镶嵌；被动不以本次法术成功为统一前提；类型不符时仅对应特效休眠 | 不用空杖白拿范围被动，又允许协作 |
| IN-C09 作用范围 | 默认本杖法术；只有写明范围被动时才影响其他来源。范围按固定镶嵌的基础范围及明确范围修正判定 | 防止把本杖加成误用为全局增幅 |
| IN-C10 同类叠加 | 同一效果组对同一受益事件取最强一次；等强按法杖顺序、固定→活动槽1→槽2选先者；不同组按声明合并 | 重叠范围不重复刷同一加成 |
| IN-C11 数值与时间 | 同参数沿GR01；无词卡时间贡献，成本为金币、槽位和适配机会；明确的冷却修正独立列明，不能暗增乘区 | 与修饰词共用数值框架，保留两类成本 |
| IN-C12 事件与计次 | 每个效果必须写按周期／尝试／成功／对象／状态施加哪个事件计；一事件对同一镶嵌至多响应一次，默认一层派生 | 阻止重复标签、多目标和派生效果无限增殖 |
| IN-C13 顺序与延迟结果 | 数值先统一合并；原词与修饰词有限子步骤按其规则，再处理明确的镶嵌后置响应；独立事件按GR07候选时点 | 保持完整事件和世界结果可追踪 |
| IN-C14 收益与范围控制 | 普通战斗仍只结算金币与词卡；休整三选一仍只选词卡；初版不做镶嵌掉落、合成、升级、出售或刷新 | 先把装配和协作跑通，再拓展外围渠道 |

### 获取、资格与更换的细节

候选资格包括渠道、当前阶段和持有上限；不根据当前法术类型锁住购买。尚未适配的镶嵌可以先买入库存，面板标明“目前无符合特效条件的法术”。同名可换镶嵌已持有时从池中移除，跨店亦不重复出售；固定镶嵌是法杖内置身份，不作为可换物品计数或单独抽取。

换杖时，原杖连同固定镶嵌回法杖库存，活动镶嵌回镶嵌库存；玩家重新选择法术绑定、镶嵌、范围与法杖顺序，再排首次冷却。不存在战中自动换杖或一件镶嵌同时支撑多杖。买入法杖不授予出战槽位；出战法杖数沿对应阶段资源规格。该规格及起始法杖名单尚需数值设计，不能用未知数量伪造真实获取概率。

镶嵌和法杖商品价逐件声明，使用现有金币，无新货币、维护费或自动退款。可不买离开；无出售、付费刷新、随机包或强制购买。候选每店的两类名额与普通词卡名额分别计，需在同预算评测中检查挤占词卡成长的问题。

### 激活、范围和冲突的细节

候选下，纯范围被动从战斗开始激活，到战斗结束或必需来源失效结束；冷却、覆盖、打断或本次无合法对象不自动关闭它。未出战、未绑合法法术或必需来源已失效则不生效，不能占一个空配置无限提供范围收益。

固定镶嵌即使没有特殊效果，也始终定义该法杖的基础范围；特殊效果类型不匹配不抹掉范围，也不禁止在法杖上绑定其他合法类型。单件效果用“或”匹配多类型仍只响应一次，明确“同时满足”才按交集判断。燃烧施加事件属于作用特征，不要求句中必须出现“燃烧”名词，不能以这类事件反改法术类型。

活动镶嵌可以通过明确词条修正基础范围，初版不默认改变范围形状或使所有法杖共享范围。范围被动在每次受益事件发生时检查目标身份和当前范围；进入范围不追溯强化已有状态，离开范围不撤销先前已合法增加的层数。

同效果组去重在单个受益事件内判断，不让一杖的计数控制另一杖。不同事件仍可分别受益。效果组必须写入词条，不能靠换名称绕过同效去重；数值可比较时取最强，无法比较的改写必须声明互斥，不能以一句“全部叠加”掩盖冲突。

### 与修饰词、状态和附加事件衔接

修饰词的通用／适配判断始终看原词。镶嵌不会把寒冷→火焰变合法，也不替玩家补未拥有的词义。源方、修饰词、本杖和范围被动的适用数值来源逐项标记，作用于同一参数时统一合并，普通数量只在完整修正后取整截断。

状态施加量的强化只进入本次新增量；不追溯改已有量，周期结算不重复应用施加量强化。范围被动增层是对原施加的修正，不生成第二次施加事件，不增加状态时长，也不自动计作第二次成功。效果禁止、免疫或不合法时，增幅不能绕过前提；原施加为合法零量时是否允许形成状态仍由该状态定义。

同一次完整法术的直接效果、修饰词有限附加子步骤与镶嵌明确的后置响应分别记录。数值修正在对应作用前完成，不能放到作用之后补算。候选后置响应按法杖公开顺序、固定镶嵌、活动槽1、槽2处理；这一顺序不改变共享释放槽“后杖覆盖前杖”的规则。

候选一层派生指：镶嵌产生的独立追加效果可带数值修正，但不能再触发任何镶嵌的事件型响应；原法术和修饰词已声明的有限子步骤可作为事件来源。每个事件每件镶嵌至多响应一次，计数归属与是否消耗本次额度须明示。独立事件采用GR07-C01时必须标其Candidate身份；完整事件后的胜负先于后续独立事件，终局后不补触发或收益。

计次按实际声明的事件推进：覆盖／打断计周期但不计释放成功；空名单可计实际释放尝试但不计成功；多目标不自动把一次成功变成多次。首战及每战计数从0开始，不因战前反复拆装或等待提前推进。

### IN-X01：简易法术加速

用户确认：装备法杖承载简易法术时，第2、4、6……次冷却各缩短1刻；第1、3、5……次不因本效果改变，不永久累计。计数以本杖的周期为单位，覆盖和打断也推进，不能通过取消把强化留到“下次成功”。多类型中只要含简易即符合，其他标签不重复触发。

候选执行补充：第n次冷却启动时记录本周期序号并一次计算本次时长；未完成冷却被R23改期仍是同一周期，不重发减冷却。被取消机会等到其名义释放段结束才进入n＋1，不能提前重启；释放时长r不受本效果影响，首次冷却起点仍在0–10刻。

冷却下限候选：镶嵌减冷却最多减到1刻；若该合法法术原本允许0刻，则保持0而不升到1，不由镶嵌额外制造0刻循环。本效果实际减量为min(1，max(0，减冷却前本次c－1))。多件减冷却须共用该下限，不能各自减到1后再相加突破；释放最早时点及当前冷却改期仍遵守既有规则。

说明例，仅用于展示含义：其他输入固定且基础c＝4、r＝1时，前四次冷却为4、3、4、3刻，周期为5、4、5、4刻；不会变成4、3、3、2。示例尚未运行验证，4／1不是正式默认参数。

### IN-X02：燃烧效果强化

用户已确认：范围内各来源施加燃烧时生效的被动。仅在一次合法燃烧施加发生时，把本次新增层数的固定修正加1；不是每跳燃烧伤害时再长1层。一次新增3层且无其他增幅时，本次变为4层，时长按原施加；不拆成3层与额外1层两个施加事件。

本范围被动中，目标只要处于该杖范围、满足燃烧作用资格及该词条明示的目标限制即可；其他法杖、环境和敌方来源的施加均可受益。没有另写阵营过滤时不暗中排除玩家或友方，界面应提示其风险。多杖同效重叠按IN-C10候选取一次；本杖被覆盖不取消另一个合法来源受到的范围强化。

燃烧每层的伤害、周期、持续时间、层数上限与合法零量规则尚未设计，本例只明确强化入口；不恢复已搁置的传播或元素参数。

## 玩家处境、行为与反馈

玩家在商店比较词卡、法杖和镶嵌的收益；战前选范围与特性，拆装以配合词句和敌人。界面明确固定／可换、影响本杖或范围、适配／休眠、周期计数、即将缩短的冷却及增层来源。希望形成专精与混搭取舍；获取稀缺性、范围辅助的体验与可读性仍需验证。
