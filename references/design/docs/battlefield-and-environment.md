## 推荐的完整版本

| 部分 | 建议 |
| --- | --- |
| 格子与占位 | 每格一份地面＋最多一个占位对象；草地上可以有树，火焰也要占一个空位 |
| 视角与前后排 | 玩家在十格之外正面观察；前后排不默认分阵营或产生遮挡防御 |
| 居中 | 单敌默认前排中格F3，多敌有固定中心向两侧的候选次序 |
| 火焰出生 | 以范围内首个合法敌人为锚点，按公开格子顺序选择其正交邻近空位；满位不挤占 |
| 邻近影响 | 本格地面＋上下左右一格，不含斜角；不同宿主各自检查属性 |
| 火焰持续 | 有限寿命，生成后下一个规定间隔才开始脉冲；结束即释放占位 |
| 树草变化 | 自身燃烧量低于点燃阈值为受火，达到后燃烧，再到烧焦阈值后永久本场烧焦 |
| 烧焦结果 | 清除燃烧并失去可燃资格；树仍占位，地面仍存在，身份与资源次数不重置 |
| 其他能力 | 不自动增加材料、掉卡、树草传火、位移或完整召唤攻击 |
| 数值与证据 | 只明确符号与合法域，具体平衡值以后设计，测试继续积累 |

## 例子

敌人F3，树位于B2草地，F2是草地空位。释放火焰选F2；后续作用F2地面、相邻F3敌人及B2的草地和树。B2的草地与树各自跨阈值变化；B3在斜角，不受这份火焰作用，B2树也不会继续传火。
