## PG00：表的读法与采用边界

1. 去重后共34种词卡：9名词、14动词、11形容词；另有19种可换镶嵌。护甲和引爆跨流派共用词义、参数、副本额度和商品名称。
2. τ是每张实际分配词卡的时间贡献；L是整句释放段时长。结果、费用和条件字段不会凭一个数字自动产生额外词卡、伤害或类型。
3. 名词在输入／引用位只提供该角色允许的对象或状态信息。例：护甲在“获得护甲”结果位提供基础6甲，在“拆甲”输入位读取目标甲；不是每引用一次护甲都给6甲。
4. 普通直接动作只在释放开始交付一次。只有“释放”沿RC07逐刻检查三刻生成／补层／回退；L不等于其他动词的伤害重复次数。
5. 两流派均有可单独运作的基础结果；本页给一套小整数、简单比例的初值以便完整代入。并未计算哪套构筑最强、调参寻找获胜输入或运行玩法测试。
6. 原句词义、HG01宿主能力、固定名单、实例失效、来源和一层触发优先。参数不能为原本非法对象补权限。

## PG-Q01：数量单位、取整与修正入口

采用GR01结构：**最终数量＝max(0，floor((基础量＋适用固定增减合计)×已声明乘数))**。层、伤害、护甲、金币、成功次数分别计量；比例换算均在最终交付前保留分数，不能每一步先取整。

- 生命、护甲、印记和火冰层数为非负整数；数量状态归零清除身份。回响是布尔许可，不参与倍率。蓄势计数是0–3，满后等待兑现；跳冷却／追加请求各沿RC有限标志。
- 默认火冰自然衰减基础1层／刻；受固有属性关系修正为0.5、1或2层／刻，按ST03累计小数进度后扣整层。主动支付／移除不套自然衰减倍率。
- 普通元素邻近每个合法目标的基础施加量＝该次作用所读元素当前层数÷4；然后合并符合条件的入量修正和目标固有属性克制。没有按目标数分摊总层数，也没有为每目标自动扣元素层数。
- 自噬取代上一条基础量和时间衰减：有合法名单才一次支付min(2，自身层数)，对各合法目标用实付层数×1作基础入量；该整次资源不逐目标重扣。零目标不支付；自耗归零后只完成当前已提交动作。
- 燃烧周期基础伤害与冰冻周期基础护甲均为宿主当前对应层数÷4。只有HG01允许的攻防宿主兑现；对树木、草地及元素本体跳过攻防，仍处理允许的状态变化。
- 入量克制只在新施加量对目标固有属性求一次；修正后的量先抵消旧元素状态，再用正余量建立新态／满足补生许可。取整后的正余量不再作为一次新增重新吃加成。
- **Q-A新增入口：**普通生成、直接补层、状态施加，以及汲取／消耗／蚀甲给元素带来的正基础补层，均在对应新增入口检查适用的范围加成；基础量来自实际支付／实际损耗。元素给自身同种共享状态补层的克制关系为中性，不能再按被取走状态原宿主属性改量。环境转化继承、既有同种量、衰减进度和异种抵消后已经求出的余量不重新加成。原动作无合法对象或无合法支付时，不检查新增加成来发起补层；基数为0的合法新增仍按完整公式求值，以最终量判断零值，不在固定加成之前先截断。
- 主动汲取的源数量扣除与目的新增量可以不同，差额来自已明示加成；源数量只消费一次。
- 双律／攻守先决定直接结果种类，按各自系数1换算基础量；再判断当前结果允许的修正及支付。冰冻逆霜同样只换结果种类和系数，不先兑现护甲、再以该护甲制造第二份伤害。
- 满溢的火伤／冰甲是新的直接基础结果4，不搬用原燃烧入量＋1或克制乘数；仍可受本杖对直接伤害／护甲结果明示的效果影响。蓄势只增强合格完整法术的直接伤害／护甲，不追溯改写后续状态周期。
- 首版不另设护甲或元素层数上限；取得量受实际卡、事件、付费和战斗时间限制。无上限层数不等于无期限战斗，有限终局另由疲劳规则保证。

两个计算例仅校对定义：元素3层时邻近基础0.75，向被该元素克制的属性施加，0.75×2后取整为1；若另有已激活且覆盖目标的余火＋1，则(0.75＋1)×2后取整为3，不能先把0.75取整成0。消耗敌甲3点时补层基础1.5，不带加成为1层；带合格余火＋1时为2层，按Q-A只计算一次。

## PG-Z01：逐类零值与成功

| 类别 | 规则处理 | 不可混淆的失败 |
| --- | --- | --- |
| 伤害／获得护甲／标记 | 对象及操作合法但最终量0，可完成一次合法结果；不创建0量状态 | 无敌人、目标死亡、词义禁止不是合法0 |
| 获得回响 | 已有回响时保留一份，合法结果可计成功；不叠追加次数 | 不能由刚生成回响的那次完整法术消费自己 |
| 释放同种补层／有合格回退对象 | 最终新增0不改状态／不触发应激，但合法0结果可计完整法术成功一次 | 没有合法对象时不以0量占位 |
| 释放新生分支 | 已有合法敌旁空格但最终量0：本刻不生成新身份，该合法零量生成尝试可计成功 | 没有合法出生格又无回退对象时无结果；0量不留下占位元素 |
| 限量主动支付 | 输入须有正量；不足上限取现有量；实际支付后换算结果0仍合法，不退款 | 无状态／无护甲不作0支付来刷成功；执行者非法不收费用 |
| 全量引爆／爆裂 | 输入须为正；已支付或顽固读取后伤害0仍沿合法结果处理 | 没有输入或无合法受术者时不先消耗 |
| 清除／净化 | 必须存在可清除的状态身份 | 不把不存在、已清空或历史身份当作成功清除 |
| 完成冷却 | 当前过程有效、原定下刻释放时为合法零改期 | 已结束历史过程无资格；取消标记不会清除 |

本表补齐逐词零值许可；合法空格但0量生成的尝试不创建身份，但可以产生一次法术成功。合法成功可推进相应计次，不保证产生有效攻防；RC03要求实际直接攻防收益才能兑现蓄势，不因计次合法而放宽。新增状态的原事件如果已经完成实际抵消，即使新态余量为0也保留已发生的抵消结果。

### 商店货架规格

每次新商店到访，从当时合格池生成**4个不同名称的词卡条目＋2个不同ID的可换镶嵌条目＋1根法杖条目**。各类别分开等概率、不放回抽取；没有保证伤害／护甲／元素各一件的隐藏规则。

- 词卡先排除已达同名3张上限者；镶嵌先排除已持有同ID者；法杖按启用期筛选，不按已有同款排除。不同商店可出售同款新实体。
- 某类别合格池少于其名额时，展示所有合格条目，剩余位置显示“本期无可售商品”；不跨类别补足，也不为补满加入未启用内容。
- 同店每个商品一份；售价按本表固定，不随金币、构筑、购买次序或时间变化。买走不补货，不能购买尚未展示的目录项。
- 普通词池和镶嵌池均按当步合格ID等概率，不因价格或启用期加权；余额不足的合法商品仍可展示，并清楚标记缺金币。
- 货架与价格首次生成后固定，节点退出沿已定保存规则；再次进入不能刷新或撤销交易。购买时再次核对额度和金币，合法才交付，旧无刷新／出售／退款规则保持。
- 法杖的固定芯不单独售卖，不把固定芯计算成第20–22个可换镶嵌。

## PG-E01：金币初值与量级参照

首版普通战斗金币基准：**基础8金币＋时间奖金0–4金币**，胜利后整体领取或放弃；同一战斗重播不重复结算。首领胜利按[RG01](../../idea-materials/M-2026-09-14-run-route-encounters-and-fatigue.md)直接结局，不再发可领取奖励包。

| 胜利成立刻T（从本场第0刻起） | 时间奖金 |
| --- | --- |
| T≤24 | 4金币 |
| 25≤T≤40 | 3金币 |
| 41≤T≤56 | 2金币 |
| 57≤T≤72 | 1金币 |
| T≥73 | 0金币 |

失败不取得该胜利收益；疲劳致胜仍按实际T落档，不重置时钟。没有额外击杀金币、连胜奖金或法术产金。节点保存锁定本场奖励规则与输入，实际胜利收益按该场固定结果兑现。

量级例：两场普通胜利且均领取，总金币16–24；未花费时可以买一件12金币镶嵌＋一张4金币词卡，取得最高两档奖金时可多买一张，仍受实际货架提供和持有额度约束。这只是币值／价格可计算性例，不是路线保证、真实购买率或“必可组成某流派”。

总体经济仍需与真实战斗数、休整数、商店到达时点和合理损耗核对；本表不声称该价格已平衡，不通过增加隐藏保底或临时金币来填成长缺口。
