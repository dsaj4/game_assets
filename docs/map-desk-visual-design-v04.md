- 猫从当前整体图完整移除，原处恢复木墙和桌面后沿；旧参考图作为历史保留。
- MD-11法杖袋占据原猫位置，沿后侧木沿横放靠置，左端收口，右端袋口露出两支杖头；原来右边竖斜放的袋子移走，场景只有一只袋子。
