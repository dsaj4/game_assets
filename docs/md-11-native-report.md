## 原生 Blender 操作和生成链

1. [build_md11.py](../art/build_md11.py)构造初始网格、绑带、实心木杆、材质与预览相机，留存生成基线。
2. 通过电脑插件操作真实Blender窗口，把`MD11_STAFF_FORK`局部X角从0°调到12°并保存，冻结为[md11-ui.blend](../art/md-11-v01/md11-ui.blend)，附[截图证据](../art/md-11-v01/ui-fork-roll-12deg.png)。
3. [publish_md11.py](../art/publish_md11.py)读取该UI存档，细化叉枝和木节、降低单件展示曝光，保存可编辑发布母版，再导出交换网格和实际渲染。全过程断言UI变换不变。
4. 从旧桌面母版载入全部原物件，追加长袋到新目录。羽毛笔组前移8.5cm、星仪前移24cm；未删除杂物，也未改变旧网格或其他资产变换。旧母版及九类独立文件保留。

重建当前交付时先加载`tools/env.ps1`，分别用`$BlenderExe --background --factory-startup --python-exit-code 1 --python art/publish_md11.py`和`art/verify_md11.py`。发布器从已冻结UI存档开始；初始生成器会重建基线和工作源，不应用于覆盖后续手工精修。
