## 画面目标

像坐在一张旧木桌前，俯身看一幅被反复翻阅的旅途地图：纸上画满城镇、坡地、树林和小路，几件有厚度的小摆件压在纸上；桌边的书、猫和金币宝箱把它包围成一个有人使用的空间。

镜头位于桌前略高处，能看见木雕和建筑的正面、屋顶与底座。地图向后倾斜并收窄，近处物件较大，远处较小；前沿和后沿的差别形成纵深。细节靠清晰轮廓与遮挡表达，地图小路仍可读，景深虚化保持克制。

## 从截图提取的层级

| 层级 | 截图中的表现 | 本稿应保持的区别 |
| --- | --- | --- |
| 纸面环境插画 | 城墙、房屋、山石、树丛和小路密集交织，建筑也有手绘透视；线条、颜色与纸面保持连续 | 建筑画在纸上，不因为画得立体就成为地点棋子。它们的边缘不脱离纸面，也不投出独立的物件接触阴影 |
| 纸上实体摆件 | 少数木制造型或标记压住环境图，有独立轮廓、遮挡关系与底部暗部 | 法师木雕、篝火、水晶球和简易地点建筑各有厚度，脚下有短而明确的接触阴影；底座不做成悬浮按钮 |
| 桌边物件 | 猫占据后沿，书和宝箱压住前沿，物件部分遮挡地图边缘 | 外围道具建立桌面的尺度和生活感，把目光围向地图中心；不赋予未经确认的功能 |

以上是对图像表现的观察，不据此判断原作实际使用了 2D、3D 或哪一种渲染技术。

## 构图与资产职责

位置以独立右侧地图画面为参照，属于整体图的摆放草案。保持“后沿—纸面—前沿”三层；视线先落到法师木雕，再沿红线进入地图纵深，最后读到环境细节。

| 资产 ID | 资产与职责 | 位置、层级及造型要求 |
| --- | --- | --- |
| MD-01 | 旧木桌与后沿 | 承载整幅画面。灰橄榄木板、墨色缝隙和磨损边角；后沿较窄，前沿有厚度，木纹服从板材方向 |
| MD-02 | 地图纸与环境画布 | 占画面中央大部，向后收窄。灰米色带橄榄调，纸边轻微卷曲；纸内密集绘制建筑、小路、山石、树林，靠局部留白整理密度 |
| MD-03 | 红色路线笔迹 | 直接落在纸上，从前景向纵深蜿蜒。暗朱红、略有干笔断续，关键段能从环境线条中辨认；具体走向仅为构图示意，不表示正式路线拓扑或可达性 |
| MD-04 | 法师木雕：玩家代表 | 地图中下部的视觉落点。削刻的帽兜或尖帽、袍身、短杖形成可辨剪影；木纹与刀痕跟随体块，底部稳稳接触纸面 |
| MD-05 | 篝火：休息代表 | 地图中段偏一侧。几段木柴围成小火堆，火焰轮廓简洁；少量暖色提亮，仍保留墨线与实体底部 |
| MD-06 | 水晶球：问号事件代表 | 地图另一侧，与篝火形成形体差异。球体与短托座清楚分开，玻璃用少数冷色亮面和暗边表达，事件含义不依赖大号悬浮问号 |
| MD-07 | 简易建筑：地点代表 | 地图较远处。体量精简的门、墙、屋顶组合，立在纸上；独立底部阴影和压住纸面笔迹的边界，使其区别于环境中画出的房屋 |
| MD-08 | 金币宝箱 | 桌边右下，部分进入前景。木箱、铁箍和可见的少量金币；金色集中在局部，体量不遮住地图主要阅读区。不定义货币数值或操作 |
| MD-09 | 猫 | 桌边右上、后沿。伏卧姿态，灰紫或灰黑毛色，以成束排线组织毛发；头与前爪清楚，身体融入暗背景。不定义角色能力或互动 |
| MD-10 | 书 | 桌边左下，切入前景。旧封皮、纸页侧面、磨损书角构成层次；角度跟随桌面，用较安静的深色承托地图。不定义菜单或入口 |

法师、篝火、水晶球、地点建筑的对应含义来自本轮用户要求。数量、精确位置、路线密度、活动结果和点击方式仍未在这里决定。

## 笔触、颜色与体积

- **轮廓先成立。** 主要剪影用较重墨线，内部结构线略细，阴影用疏密排线；线条有轻微弯曲与断续，粗细跟随物件结构。屋瓦、木雕刀痕和毛发分别沿自己的生长或搭接方向组织。
- **纸面繁密但有通路。** 建筑聚落和坡地之间留下可辨的小路与浅色地面；密度在聚落和边缘增高，在红线路段和棋子脚边降低。地图中心也有环境叙事，不能只剩空纸与几个孤立图标。
- **灰橄榄是底色。** 旧纸为灰米白，木头与石头用灰褐、灰绿和炭黑。暗朱红路线、篝火暖色、水晶球冷色、金币暗金分别局部出现，避免所有对象都争夺最高亮度。
- **实体靠接触关系。** 摆件底部最暗，阴影短而方向一致；木雕边缘压住纸上的线，建筑底座遮住局部道路，卷纸在桌面留下窄阴影。屋顶与墙面保持清楚的明暗转折，材质整体偏哑光。
- **前后尺度一致。** 棋子、书、宝箱和猫共用同一桌面透视；近处前景可有较强遮挡，远处保持体量收小。避免每件资产各用一套展示角度。

## 后续组件制作应锁定的条件

整体方向已确认，以这张整体图作为机位、透视观感、前后尺度、纸色、墨线粗细和阴影方向的参照。分件图用隔离多视图说明结构，小角标只辅助读材质与尺度；位置和遮挡仍以整体图为准。MD-01／MD-08 小角标的垫底画法存在偏差，已在建模文稿中纠正：地图铺在桌上，宝箱留在右下桌边。

环境画布与立体资产分别制作：MD-02 包含纸上建筑和小路；MD-04 至 MD-07 承担真正站在纸上的造型。红线单独保留，便于修构图，不把概念图中的线段直接固化成正式关卡规则。所有图只作为美术方向与制作参考，不从图中新增玩法结论。

## 已完成分件图与后续回看顺序

1. **MD-01、MD-02、MD-03：桌面、地图画布、红线。** 先确认纸面密度、建筑小路、透视和前后留白，建立所有组件共同的底图。
2. **MD-04：法师木雕。** 确认玩家代表的剪影、木雕刀痕和在地图上的真实占地，作为其余摆件的尺度基准。
3. **MD-05、MD-06、MD-07：篝火、水晶球、地点建筑。** 逐件确认形体和材质，每完成一件就放回整体图检查，与纸面插画保持可辨层级。
4. **MD-10、MD-08、MD-09：书、金币宝箱、猫。** 最后确定外围遮挡和叙事细节，让它们配合已经稳定的地图构图。
5. **回看整体。** 核对资产加入后红线是否仍清楚、木雕是否仍是视觉落点、前景是否侵占主要地图区域，再决定是否进入下一阶段制作。

当前 MD-01 至 MD-10 均已生成并审阅，采用 1536 × 1024 横向建模板。地图与红线各做一次修订，当前选用 v02；首次图保留追溯。多视图存在局部透视与方位偏差，建模文稿逐件记录校准项；未新建 .blend 模型或接入引擎。上列顺序保留为后续结合整体图回看的建议，不表示已完成三维合成验证。
