# 独立设计方法与评议范围

2026-09-19。用户明确要求不同 agent 根据功能、风格背景重新构思，本批按该要求分成三个独立任务。每名设计者都用 `fork_turns=none` 启动，未继承旧页面对话；只接收[共同功能简报](brief.md)、自己的风格方向和交付约定。

| 独立任务 | 唯一负责目录 | 提供的风格背景 |
| --- | --- | --- |
| fieldcraft_design | fieldcraft/ | 旅途手作、自然博物、游侠工艺 |
| woodcut_design | woodcut/ | 民俗暗黑木刻、中古黑字印刷 |
| observatory_design | observatory/ | 黄铜天文仪器、古典秘术测绘 |

没有向设计者发送旧页面截图、旧组件稿、旧排版坐标或其他方向图片。设计者自行写说明与提示词，并各自调用内置 image_gen；主 agent 负责共同功能澄清、收集、查看效果图和归档。不把并行 agent 描述为不同基础模型，也不把生成图描述为原生模型或可运行界面。

旧版“必须沿用某张整体图”的阶段约束由本轮重新设计请求覆盖；袋中出战／架上备战、只读法术、四出战上限等功能约束仍保留。公共简报中的1536×2048仅用于统一展示比例，布局与信息主次由各设计者决定。

## 评议重点

- 在既有功能范围内，信息组织、视觉焦点和控件表达是否有区别；颜色和纹理不同不足以说明布局已经创新。
- 当前选中的法杖、出战／备用归属、可调整项与只读信息是否易于辨认。
- 两个可换槽是否与固定芯区分；2×5范围、F3四格、冷却起点与释放时间是否表达正确。
- 保存、返回、出战转移与顺序调整的意图是否可辨识；不要求每个潜在状态同时显示。
- 图片中的字形、物件计数与细节是否出错。概念探索可以带有明确记录的生成限制，不能据此更改玩法规则。

最终输出为 VisualExplorationDraft / NeedsReview。尚未选择最终方向；不修改 v03 Blender 母版、不生成新原生模型、不进行字体代码化或Godot实现。图片来自三名 agent 的独立生成，源图、提示词、方法及已知缺口保存在各自目录。
