# 法杖管理页面 · 独立设计公共简报

2026-09-19。用户认为当前面板呆板，要求不同 agent 只根据功能、风格等背景独立重新设计并生图。本简报不包含任何旧页面截图、排版图、旧提示词或尺寸坐标。

目标：为《言咒》独立奇幻游戏设计法杖管理页面，让玩家理解目前的出战配置、看清选中法杖，并便捷地调整配置。只做效果探索，不建模、不写字体代码、不接入游戏。

## 已有功能约束

- 袋中出战、架上备战：最多四根出战法杖由展开皮革袋承载，备用库存以独立架体表达。两者属于同一持有库存；不得混淆。位置、形态、尺度、透视、视觉分组由设计者决定。
- 示例持有6根，4根出战，2根备用原木杖；这是示例，不是起始赠送或库存总上限。
- 四根出战依次为节律杖、原木杖、余火杖、原木杖。对应已绑定法术为伤害敌人、获得护甲、释放火焰、火焰伤害敌人。
- 可以选择法杖、调整出战顺序、把出战杖移至备战架、由备战架换入出战。
- 本页不编辑法术或词卡。绑定法术名称、类型、冷却和释放参数是只读信息。
- 选中节律杖：只读法术类型“简易”。固定芯“节律芯”不可更换；另有恰好两个可换镶嵌槽，示例均为空。固定芯效果为“偶数次冷却 -1刻（简易）”。
- 范围锚点可配置，用前后2排、每排5格表达。上排是后排B，下排是前排F。当前F3：上排只亮第3格，下排亮第2/3/4格，锚点在下排第3格。
- 首次冷却起点0–10刻可调整；当前0。只读冷却4刻、释放1刻，首次释放4刻。起点不是释放时间。
- 首轮名义释放摘要：①4刻、②5刻、③7–9刻、④8刻；名义计划战中可能改期。
- 支持保存配置、返回地图、未保存状态。此页不直接开战。不新增出售、分解、强化、修理、耐久、负重或稀有度机制。

## 设计自由与提交

用户希望从功能和氛围重新推导信息组织。布局、视线顺序、控件形态、信息主次、材质语言、字体全部自主设计；不要从旧版界面延伸，不查看其他 agent 方案。

面向游戏中的单一页面，公共展示比例为3:4纵向（建议1536×2048，允许工具原生同等比例），只表示当前独立左页，不改变游戏横屏目标。中文可先艺术化绘制，不需要实际字库。要有清楚的主动作和选中状态，不必把全部次要信息同等强调；只有必要的功能信息出现在画面。

每名 agent 独立构思一种指定风格，先写自己的设计说明和完整提示词，再自己调用内置 image_gen 生成一张完整页面。新图生成不传任何旧截图或其他方案，也不使用会话历史图片。检查实际输出并如实记录遗漏、错字或布局问题；交付选用图、设计说明、提示词和来源哈希。

已有游戏规则仅作为功能输入。新布局都是 VisualExplorationDraft / NeedsReview，不是已采纳设计；原生 v03 资产保留。
