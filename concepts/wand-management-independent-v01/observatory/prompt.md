Use case: ui-mockup
Create ONE new full-page Chinese fantasy game UI concept image for 《言咒》, portrait 3:4, ideally 1536×2048. This is an independently invented single wand-management page, not a slide, not a component sheet, not a photograph of a monitor. No reference images. High-fidelity hand-painted 2.5D game concept art with exceptionally legible Chinese typography. Entire interface inside frame; no cropped labels.

ART DIRECTION — “星盘行囊”
A working occult cartographer's brass instrument, precise yet handmade: old satin brass with fine engraved astronomical scales, oxblood and saddle-brown supple leather, ivory vellum, deep blue-green ink, ebony wood. Tiny asymmetric handwork, restrained tarnish, warm raking lamplight, cool shadow, gorgeous tactile edges. A single large eccentric astrolabe arc physically unites the page. This is ancient fantasy surveying apparatus, not modern sci-fi, not a SaaS dashboard. Use real material objects and graceful asymmetry rather than a grid of rectangular cards. Black-green backdrop is calm and uncluttered. Selected item accent is warm vermilion and ivory, not neon. Typography reads like carefully set contemporary Chinese Song/Ming characters printed on historical objects, never illegible pseudo-glyphs. Game functions should be instantly understandable before ornament.
